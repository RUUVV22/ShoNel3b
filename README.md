# شو نلعب؟ — ألعاب طاولة وسهرات جماعية

> جاهز للرفع إلى GitHub: تثبيت موحّد عبر npm workspaces، فحص تلقائي عبر GitHub Actions، نشر واجهة الويب على GitHub Pages، وملف Docker مستقل للخادم. راجع [دليل النشر](./DEPLOYMENT.md) قبل تفعيل Pages.

**شو نلعب؟** منصة ألعاب جماعية فيها غرفة ثابتة تجمع الأصدقاء. يختار المضيف اللعبة من الردهة، وتبقى المجموعة داخل الغرفة بعد كل جولة. كود نيمز هي اللعبة الأولى، مع تصميم قابل للتوسعة بواسطة وحدات ألعاب منفصلة.

## ما تم تنفيذه

- إنشاء غرفة برمز فريد من خمسة أحرف والانضمام بالرمز أو QR يعمل من كاميرا الهاتف أو من داخل التطبيق.
- رابط HTTPS للمشاركة، ومخطط `shonel3b://join/A7K92` مع دعم `codenames://` القديم.
- تطبيق ويب قابل للتثبيت على شاشة iPhone وAndroid مع أيقونة، manifest، وservice worker.
- ردهة شو نلعب تعرض رمز الغرفة والمضيف واللاعبين على هيئة بطاقات شخصيات واختيار اللعبة المباشر.
- المضيف فقط يختار اللعبة عبر `lobby:select-game` ويبدأ الجولة. كود نيمز هي الوحيدة المتاحة في هذه المرحلة.
- عند نهاية الجولة ترجع المجموعة لنفس الردهة بلا قطع الاتصال أو إنشاء غرفة جديدة.
- ردهة مباشرة تعرض الاتصال والفريق والدور والمضيف.
- اختيار كل لاعب لفريقه بنفسه، مع بقاء إدارة الأدوار والإزالة وبدء الجولة لدى المضيف.
- لوحة عربية من 25 بطاقة تُختار عشوائياً من قاعدة قابلة للتوسعة تضم أكثر من 250 كلمة.
- توزيع 9/8/7/1 مع اختيار الفريق البادئ عشوائياً.
- تلميحات عربية مع سجل تلميحات الجولة ظاهر للاعبين والقادة، وعدد المحاولات وإنهاء الدور.
- بطاقة موت، فوز بكشف كل الكلمات، إعادة الجولة، والعودة إلى الردهة.
- تصفية أمنية لحالة اللوحة: لا يرسل الخادم هوية البطاقة المخفية إلى اللاعب العادي.
- استعادة الجلسة بعد انقطاع الشبكة، نقل الاستضافة، وحالة اتصال واضحة.
- هوية طاولة Retro: **Plum #351326 / Coral #E75A3C / Mustard #F2B529 / Cream #FFF0CF**، خلفية ورقية، بطاقات شخصيات، حدود عريضة وظلال، وتأثير قلب البطاقة وارتدادها.
- ملفات شعار العربية والإنجليزية في `assets/` تُستخدم مباشرة مع مفتاح تبديل اللغة في الواجهة. محتوى لعبة كود نيمز نفسه لا يزال بالعربية.
- الحفاظ على GSAP والمؤثرات الصوتية العشرة وسجل التلميحات واختيار الفريق.
- أخطاء عربية للغرفة والاتصال والصلاحيات وحالة الجولة.

## المتطلبات

- Node.js `22.13+` (تم التطوير والتحقق باستخدام Node `24.12.0`).
- npm `11+`.
- لتشغيل Android محلياً: Android Studio/SDK وADB أو هاتف عليه Expo Go.
- للبناء الأصلي على Android مع Expo SDK 57: JDK 17 وAndroid SDK Platform 36.
- بناء iOS الأصلي يحتاج macOS وXcode؛ ويمكن تطوير JavaScript عبر Expo Go على iPhone.

> على هذا الجهاز يوجد JDK 17، لكن أمر `java` الافتراضي يشير إلى Java 8. قبل بناء Android أصلياً اضبط `JAVA_HOME` و`PATH` كما في القسم أدناه.

## التشغيل السريع

لتشغيل خادم اللعبة وExpo معًا من نافذة واحدة:

```powershell
npm run dev
```

بعد ظهور رمز QR، امسحه باستخدام Expo Go أو اضغط `a` لفتح محاكي Android. أوقف الخادمين معًا باستخدام `Ctrl+C`. إذا كان خادم اللعبة يعمل مسبقًا على المنفذ 3001، يعيد الأمر استخدامه بدل إظهار خطأ تعارض المنفذ.

### التشغيل محليًا في المتصفح

لتشغيل اللعبة كصفحة ويب عادية مع الخادم من أمر واحد:

```powershell
npm run web
```

ثم افتح `http://localhost:8081`. يستخدم المتصفح `http://localhost:3001` لخادم اللعبة تلقائيًا.

### التشغيل على iPhone عبر Expo Go

شغّل `npm run dev` واجعل iPhone والحاسوب على شبكة Wi-Fi نفسها، ثم امسح QR. يكتشف التطبيق عنوان LAN للحاسوب من Expo تلقائيًا؛ لا يستخدم `localhost` على الهاتف لأن `localhost` هناك يعني iPhone نفسه. إذا ظهرت الحالة «غير متصل»، اسمح لـNode.js على الشبكات الخاصة في Windows Firewall وتأكد من إمكانية الوصول إلى المنفذين 8081 و3001.

افتح نافذتي PowerShell داخل مجلد المشروع.

### 1) تشغيل الخادم

```powershell
npm run server
```

يعمل الخادم على `http://0.0.0.0:3001`. للتحقق:

```powershell
Invoke-RestMethod http://127.0.0.1:3001/health
```

### 2) تشغيل تطبيق React Native

لمحاكي Android:

```powershell
$env:EXPO_PUBLIC_SERVER_URL = 'http://10.0.2.2:3001'
npm run android
```

لـ iOS Simulator على macOS:

```bash
EXPO_PUBLIC_SERVER_URL=http://localhost:3001 npm run ios
```

يمكن أيضاً تشغيل Metro فقط ثم مسح الرمز في Expo Go:

```powershell
npm start
```

## هاتف حقيقي أو أكثر من جهاز

1. اجعل الحاسوب والهواتف على شبكة Wi‑Fi واحدة.
2. اعرف عنوان IPv4 للحاسوب باستخدام `ipconfig`، وليكن مثلاً `192.168.1.20`.
3. شغّل الخادم، واسمح للمنفذ TCP 3001 في جدار حماية Windows عند الطلب.
4. شغّل Expo بهذا العنوان:

   ```powershell
   $env:EXPO_PUBLIC_SERVER_URL = 'http://192.168.1.20:3001'
   npm start
   ```

5. يمكن تغيير عنوان الخادم أيضاً من زر الخادم أعلى الشاشة الرئيسية داخل التطبيق.
6. افتح المشروع على جهازين أو أكثر، أنشئ غرفة من الأول، وانضم من البقية بالرمز أو QR.

## تجربة أربعة عملاء بسرعة

تتطلب الجولة أربعة لاعبين على الأقل: قائد ولاعب لكل فريق. التعيين التلقائي لأول أربعة هو:

1. قائد أحمر (المضيف).
2. قائد أزرق.
3. لاعب أحمر.
4. لاعب أزرق.

يمكن استخدام هواتف متعددة، أو محاكيات متعددة، أو مزيج منهما. كل محاكي Android يصل إلى الخادم على `10.0.2.2:3001`.

## QR والروابط العميقة

- ماسح QR داخل التطبيق يدعم HTTPS و`shonel3b://join/ROOM` وروابط `codenames://join/ROOM` القديمة.
- `scheme` وAndroid `intentFilters` ومعرّفات الحزمة مضافة في `app.json`، لذلك يعمل فتح الرابط على مستوى النظام بعد إنشاء Development Build أو نسخة مستقلة.
- لتجربة المخطط في نسخة Android أصلية:

  ```powershell
  npx expo prebuild
  npx expo run:android
  adb shell am start -a android.intent.action.VIEW -d "shonel3b://join/A7K92"
  ```

- App Links عبر `https://` تحتاج مستقبلاً إلى نطاق فعلي، ملف `/.well-known/assetlinks.json` في Android، وAssociated Domains في iOS. المخطط الحالي لا يحتاج خادماً ويب.

## إعداد Android الأصلي على هذا الجهاز

اضبط JDK 17 وAndroid SDK للجلسة الحالية:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.11.9-hotspot'
$env:ANDROID_HOME = 'C:\Users\islam\AppData\Local\Android\Sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:Path = "$env:JAVA_HOME\bin;$env:ANDROID_HOME\platform-tools;$env:ANDROID_HOME\emulator;$env:Path"
```

Expo SDK 57 يستهدف Android compile/target SDK 36. إذا أردت `npx expo run:android`، ثبّت Platform 36 وBuild Tools المتوافقين من Android Studio SDK Manager أولاً. Expo Go لا يحتاج إنشاء مجلدات `android/ios` داخل هذا المشروع.

## إضافة كلمات أو ميزات

- أضف حزمة كلمات داخل `server/src/data/arabicWords.js`؛ التجميع وإزالة التكرار تلقائيان.
- `RoomManager` معزول عن Socket.IO، ما يسهل إضافة Redis أو حفظ دائم أو مطابقة عامة لاحقاً.
- يمكن توسيع حالة الغرفة للإحصاءات واللوحات والحسابات من دون تغيير بروتوكول إخفاء البطاقات.
- `mobile/services/sounds.js` نقطة مركزية لإضافة ملفات صوتية حقيقية مع بقاء خيار الكتم.
