## Arabic voice-over — integrated
The audio package was generated with ElevenLabs on 20 October 2026.

- **Voice:** Bilal — male Jordanian/Levantine baritone, deep theatrical suspense.
- **Recorded files:** `assets/scorpion-narration/*.mp3` (43 unique narrated cues).
- **Runtime cue IDs:** `mobile/constants/scorpionNarration.js` (56 cues). Repeated copied-role close announcements reuse `copycat_close.mp3` rather than storing duplicate recordings.
- **Manifest:** `mobile/constants/scorpionNarrationSources.js` (auto-generated by the script below).
- **Playback:** `mobile/components/ScorpionAudioLayer.js` and `mobile/services/scorpionAudio.js`.
- Private copied-role announcements are never broadcast to other players: use the remote/audio-per-device setting on the actor's device. Same-room mode plays public narration only on the host device.
- Audio narration never changes game state, role visibility, or server-authoritative phase timers.
- Narration players are created lazily to avoid mounting dozens of active decoders on mobile.

## Sound effects — integrated
The game has 19 ElevenLabs-generated MP3s in `assets/scorpion-sfx/`:

| Moment | Sound IDs |
| --- | --- |
| New deck/card deal/reveal | `shuffle_cards`, `deal_card`, `flip_card` |
| Tense nighttime landscape | `courtyard_ambience` (30-second loop), `night_bell` |
| Night roles | `role_wake`, `role_sleep`, `secret_look` |
| Card interactions | `select_card`, `deselect_card`, `replace_card` |
| Dawn, timers, voting | `dawn_transition`, `timer_warning`, `vote_select`, `vote_confirm` |
| Results | `results_reveal`, `win_sting`, `lose_sting` |
| UI confirmation | `button_click` |

Effects are registered in `mobile/constants/scorpionSfx.js` and played from the game screen.
Audio always respects the user's mute state. The player must activate sound in the game.
Same-room mode plays shared audio on the host; remote mode allows every opted-in device to hear the announcements.
Private card actions use quiet local playback.

## Build / verification
After changing or replacing MP3s, regenerate the static Metro require maps:

```bash
npm run scorpion:audio:prepare
npm run build:web
npm test
```

The prepare script only includes files that exist. For mobile builds, run the preparation script before starting a new Expo build. Never ship an ElevenLabs API key in the mobile app.

The optional `scripts/import-scorpion-elevenlabs.js` utility imports temporary signed links from a manifest created by the assistant. Those temporary manifests are automatically deleted and are not required by the app.
## October 20: selected-deck night flow and voice timing

- Only night roles included in the host's **selected cards** receive turns. The order follows the standard role sequence but skips every role not selected. The mimic's private copied-helper/copied-night-girl turn is dynamically added only when that specific role is copied. Cards do not have to be in a player's hand to count as selected: cards in the middle still count as selected roles.
- The base 16-card catalog consists of eleven unique non-villager/non-companion cards, two companions, and three villagers. For 14–16-player games, add one extra villager per player above 13 (up to six villagers total). All villager copies use `12-muwatin-1.png`; image files 13 and 14 are not used.
- Because players need one card each plus **three center cards**, ليلة العقارب supports **4–16 players**. The setup pool scales from 16 cards for up to 13 players to 19 cards for 16 players. Other Sho Nel3b games retain their own limits.
- MP3 durations are measured with `node scripts/generate-scorpion-durations.cjs` (ffprobe required for new files); resulting synchronized metadata is `server/src/games/scorpionCueDurations.json`. After adding/replacing narration files regenerate this metadata and rebuild.
- Each active public role announces its opening at the start of its phase, and the ability opens after the audio finishes (plus a short buffer). Closing speech starts at least 3 seconds before the server's phase deadline, or earlier for longer closing recordings, to finish before the next turn.
- Private copied-role open and close audio is played only on the actor's opted-in device, never broadcast to the room.
- Background ambience and ordinary SFX are mixed beneath the narrator and duck while speech plays. Dramatic transitions like night bells, dawn, and results use louder (still narration-safe) accents. Existing mute controls are respected.
- **العقربة** when alone: pick exactly two different center cards in sequence. The result reveals only whether they belong to the same team; the actual card identities stay hidden and the center cards are not swapped. With a teammate, acknowledge the teammate reveal instead. The UI walks the actor through first/second selection.
- Regression tests in `server/test/scorpion-audio-flow.test.js` cover the 16-card pool, selected-only turns, precise recorded-cue phase times, and conditional mimic turns.
